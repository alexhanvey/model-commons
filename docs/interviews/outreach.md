# Phase 0 Outreach

## Contributor message

> Hi — I’m working on a community-owned small-model lab. We’re testing whether people with idle NVIDIA GPUs can contribute compute, run small evaluation or LoRA jobs, and earn non-cash community points for beta inference access.
>
> I’m not selling anything. I’m trying to understand whether this is useful and what would make you trust or distrust it. Would you be open to a 15-minute conversation?
>
> Useful context if you have it: GPU model, OS, how often it’s idle, and whether you’ve run Folding@home/BOINC/Salad before.

## User message

> Hi — I’m working on a community-owned small-model lab. We’re testing a small open model for tool calling / function calling, aimed at developers building local or agentic apps.
>
> I’m not selling anything. I’m trying to understand what small models you use today, what breaks, and whether a community fine-tune would be useful. Would you be open to a 15-minute conversation?

## Commitments

Ask at the end:

- Contributor: “Would you be willing to run one benchmark and one small job during the beta?”
- User: “Would you be willing to try the API for a week and give feedback?”

Record commitments in `docs/specs/validation.md`.

## Notes

- Do not promise payment.
- Do not promise unlimited inference.
- Do not call points an investment.
- Do not record without permission.
- Do not collect sensitive personal data.
