# Legal and Licensing Checklist

Status: Draft — Phase 0
Not legal advice. Review with counsel before public release or paid service.

## Base model

- [ ] License allows fine-tuning.
- [ ] License allows redistribution or open-weight release.
- [ ] License allows commercial use, if applicable.
- [ ] License notice requirements documented.
- [ ] Acceptable-use restrictions documented.

## Dataset

- [ ] Source license identified.
- [ ] Training use allowed.
- [ ] Model release allowed.
- [ ] Redistribution allowed, if dataset is released.
- [ ] PII review completed.
- [ ] Copyright review completed.
- [ ] Provenance documented.

## Code

- [ ] Project code license chosen (Apache-2.0 proposed).
- [ ] Third-party notices included.
- [ ] Dependency licenses reviewed.
- [ ] Contributor license agreement or DCO chosen.

## Model release

- [ ] Model license chosen.
- [ ] Base model attribution included.
- [ ] Dataset attribution included.
- [ ] Model card includes limitations.
- [ ] Export-control review completed if applicable.
- [ ] AI disclosure review completed.

## Points

- [ ] Points are non-contractual.
- [ ] No cash value.
- [ ] No transfers.
- [ ] No investment or equity language.
- [ ] Beta-only terms published.
- [ ] Admin discretion disclosed.

## Privacy

- [ ] Privacy policy drafted.
- [ ] No prompt/completion logging by default.
- [ ] Data retention documented.
- [ ] Data deletion process documented.
- [ ] Cookie/session policy documented.
- [ ] GDPR review if EU users.

## Terms

- [ ] Terms of service drafted.
- [ ] Acceptable use policy drafted.
- [ ] Abuse reporting process drafted.
- [ ] Liability limitations reviewed.

## Contributor terms

- [ ] Compute contribution terms drafted.
- [ ] Data contribution agreement drafted.
- [ ] Code contribution terms drafted.
- [ ] No employment or wage claim implied.

## Paid service (future)

- [ ] Terms reviewed before accepting money.
- [ ] Refund policy.
- [ ] Tax/VAT review.
- [ ] Invoicing.
- [ ] Consumer protection.
- [ ] AML/KYC if required.
