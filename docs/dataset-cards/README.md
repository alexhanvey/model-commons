# Dataset Cards

Every released dataset needs a card with:

- Source, URL, and license.
- Collection method and consent basis, if applicable.
- Preprocessing: normalization, deduplication, PII scrubbing, and filtering.
- Split sizes and checksums.
- Known gaps, biases, and prohibited uses.
- Contamination checks against evaluation sets.
- Retention and deletion policy.

Do not release data with unclear licensing or personal information. See
[`docs/data-policy.md`](../data-policy.md).
